# OSBUNK

OSBUNK is a standalone bunker operating system for CC:Tweaked computers.

## Installation

Run on a CC:Tweaked computer:

    wget run https://raw.githubusercontent.com/Frez7373/OSBUNK/main/install.lua

HTTP access must be enabled in the computer configuration.

## Included

- Boot manager and startup loader
- Desktop-style launcher
- File Manager
- Built-in Terminal
- System Monitor
- Device Center
- Notes
- Mouse/touch input support
- Automatic installation and repair from GitHub
- Detection of modems, monitors, drives, printers and speakers

This project is standalone and does not depend on any other repository.
